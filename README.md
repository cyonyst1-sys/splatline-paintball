# Splatline Paintball

A top-down 4v4 paintball game that runs in the browser. One file, no build step, no dependencies.

You play on Blue with three bot teammates against four Red bots. One hit and you're out; the first team to win 3 rounds takes the match.

## Play

Open `index.html` in a browser, or play the GitHub Pages build if it's enabled for this repo.

| Control | Action |
| --- | --- |
| WASD / arrows | Move |
| Mouse | Aim |
| Left click (hold) | Shoot |
| Shift | Sprint (less accurate) |
| R | Reload (20-ball hopper) |
| P / Esc | Pause |

## Features

- Bots take cover behind bunkers, strafe in firefights, lead moving targets and fall back to reload
- Three difficulty levels (Easy, Normal, Hard)
- Paint splats build up on the field and on bunkers throughout a round
- Kill feed, hopper counter and procedural sound effects (Web Audio)

Keyboard and mouse only; there are no touch controls yet.
